# Latihan Next.js dengan Ngrok 🌐
**Experimental Local Development with External Access**

## 🌟 Overview
This project is a playground for learning Next.js and exploring how to expose local development servers to the internet using Ngrok. It's a great setup for testing webhooks, mobile testing, or sharing progress with collaborators without deploying to a staging server.

## 🛠 Built With
- **Next.js:** For building modern React applications.
- **React:** For declarative UI components.
- **Ngrok:** For secure tunneling of local servers.
- **CSS Modules:** For scoped and maintainable styling.

## 🚀 Key Features
- **Local Tunneling:** Easily share your local environment with others.
- **Next.js Routing:** Exploring the App router and standard routing patterns.
- **Responsive Layout:** Basic responsive template for various devices.
- **Developer Workflow:** Optimized for quick testing and iteration.

## ⚙️ Setup & Installation
1. **Clone the repository:**
   ```bash
   git clone https://github.com/StickGo/latihan-nextjs-ngrok.git
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Run the development server:**
   ```bash
   npm run dev
   ```
4. **Expose with Ngrok:**
   In a separate terminal, run:
   ```bash
   ngrok http 3000
   ```
5. **Access remotely:** Use the URL provided by Ngrok to access your local app from anywhere.
